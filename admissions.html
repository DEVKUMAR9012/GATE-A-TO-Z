Admissions

Admission Flows

IIT / IISc Admissions (via COAP)

COAP (Common Offer Acceptance Portal) is where all participating IITs/IISc upload their admission offers.

⚠ COAP is NOT an application portal You must apply separately to each individual IIT/IISc. Only if they select you, they will push the offer to your COAP dashboard to Accept, Retain, or Reject.

Selection may involve written coding tests and technical interviews, especially for MS (Research) and AI programs. A high GATE score shortlists you, but doesn't guarantee the seat.

NIT / IIIT / CFTI Admissions (via CCMT)

CCMT is highly centralized. You register once, pay a single fee, and create a preference list of institutes.

Centralized Flow Registration → Choice Filling → Locking → Seat Allotment (Algorithmic based on GATE score) → Upgradation/Float → Document Verification → Reporting.
⚠ CCMT Changes Participating institutes and program mappings can change every year. Always refer to the latest brochure.
